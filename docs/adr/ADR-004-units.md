# ADR-004. Единицы

Статус: принято 2026-09-28. Подтверждено спайком: куб 10 мм дал объём 1.0 см³ и bbox 10×10×10 мм.

Fusion API хранит длины в сантиметрах, углы в радианах, массу в килограммах, объём в см³, площадь в см². Отображение документа — миллиметры (`FusionUnitsManager.distanceDisplayUnits`).

Граница одна: `fca_rt/units.py` и зеркало `fusion_cad_ai/units.py`.

- Наружу уходят только поля с суффиксами `_mm`, `_mm2`, `_mm3`, `_deg`, `_g`. Поле длины без суффикса — ошибка контракта.
- В API значения передаются через `ValueInput.createByString("<число> mm")` или выражением user parameter. `createByReal` для длин не используется: реал интерпретируется как сантиметры.
- Размер без единиц на входе инструмента — `UNIT_AMBIGUOUS` / `AmbiguousUnitError`.
- Перевод: мм = см × 10, мм³ = см³ × 1000, мм² = см² × 100, градусы = радианы × 180/π, граммы = кг × 1000.
