# ADR-005. Документы Fusion

Статус: принято 2026-09-28.

`new_design` создаёт видимый документ (API не умеет невидимые), ставит имя `FCA_<model>`, `designType = Parametric`, `designIntent = Hybrid`, отображение длин — миллиметры, атрибут `fca.owner = fusion-cad-ai`.

Повторный `new_design` с тем же именем активирует уже открытый `FCA_<model>` и не плодит документы. Пересборка чистит таймлайн этого документа, а не закрывает его.

Мутирующие операции (`execute`, `execute_file`, `params_set`, `reset`, `export`, импорт) отказываются с `NOT_FCA_DOCUMENT`, если активный документ не наш. Так спайк не задевает чужие открытые файлы.

`reset` требует `confirm=true` и тоже работает только с `FCA_*`.

Закрытие, сохранение в облако и удаление документов автоматике запрещены. `cloud_save` / `cloud_open` требуют `confirm=true` и явного согласия человека. Несохранённые `FCA_*` сами не закрываем: лимит 10 активных документов относится к Personal Use, а текущая лицензия — Trial (см. спайк), и закрытие без спроса уничтожит несохранённую работу.

Сборки живут в одном документе: компоненты и occurrences, без отдельных документов на деталь.
