# ADR-002. Источник истины

Статус: принято 2026-09-28.

Истина — Python-модель в `models/` (dataclass параметров в миллиметрах и функция `build(ctx, params)`) плюс user parameters, которые `build` создаёт в документе Fusion. Файл `.f3d` — производный артефакт экспорта, его нет в git.

Один и тот же файл модели исполняют CLI и MCP. Копии «для песочницы» не делаем.

Если параметры поменяли в интерфейсе Fusion, `params_get` показывает diff против dataclass. Обратная запись в `.py` только руками и отдельным коммитом: инструмент сам файл модели не переписывает.

`adsk` импортируется только внутри `build()` и внутри `fca_rt`. Датакласс параметров импортируется без Fusion.
