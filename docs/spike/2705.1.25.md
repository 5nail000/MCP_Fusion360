# Спайк официального Fusion MCP — билд 2705.1.25

Дата: 2026-09-28. Машина: Windows 10 19045, Fusion `2705.1.25`, Python внутри Fusion `3.14`.
Сырые ответы: `2705.1.25.raw.json`, `2705.1.25.followup.json`. Снимок инструментов: `../official-fusion-mcp/2705.1.25.json`.

Документ `FCA_spike` создан спайком, не сохранён в облако и не закрыт. Его можно закрыть без сохранения.

## Транспорт

- URL `http://127.0.0.1:27182/mcp`, протокол `2025-06-18`, сервер `MCP Server Adapter` 1.0.0.
- Ответ — обычный JSON, сессия в заголовке `Mcp-Session-Id`. Prompts нет. Инструментов 4, resources 51 (все Electronics).
- `urllib` и `httpx` получают HTTP 502 на пустом теле. Клиент обязан слать `Expect: 100-continue`, затем тело после `HTTP/1.1 100 Continue`. Так делает PowerShell. На ответе стоит `Keep-Alive: timeout=5, max=5`, поэтому каждое обращение идёт своим соединением с `Connection: close`.

## Лицензия

Пользователь указал Personal Use. Живой `fusion_mcp_read licensing` в этот день ответил иначе: `licenseTypeSummary = Trial`, `isTrial = true`, `isPremium/isUltimate = true`, срок `2026-10-28` (день 2 из trial), активные расширения Design, Simulation, Manufacturing. Поэтому IGES на этой машине экспортируется, хотя в Personal Use его нет.

Инструменты не зашивают тип лицензии. `health_check` читает снимок, а `LICENSE_BLOCKED` ставится, когда API отказывает. После окончания trial набор форматов нужно перепроверить `scripts/smoke.py`.

## Что не гонялось и почему

- Скрипт на 150 с. `sleep(4)` уже показал, что скрипт занимает главный поток Fusion на всё своё время: 150 с заморозили бы окно. Долгие операции (CAM, рендер) идут через `jobs`: скрипт только стартует future и сразу возвращается, прогресс читает `job_status`.
- Свёрнутое окно. Захват вида снят при обычном окне. Пустой кадр при свёрнутом окне остаётся риском: `render_view` проверяет размер PNG и пишет файл в `renders/`.
- Диалог команды вроде Extrude. В момент спайка активен `SelectCommand` (`isDefaultCommand=true`), скрипты прошли. Мутирующие вызовы заранее читают `activeCommand` и при открытом диалоге возвращают `COMMAND_DIALOG_OPEN`.
- Полный toolpath, локальный рендер и чертёж. API на месте, но toolpath и рендер блокируют UI на минуты, а `createDrawing` требует сохранённый DataFile. Это фазы 7a–7f, не спайк.

## Решение

См. ADR-001. Условия для своего моста не сработали: состояние живёт в интерпретаторе Fusion, p50 далёк от 3 с. Версия 1 ходит в Fusion через официальный MCP. Мост описан в `docs/protocol.md` и не поставляется.
