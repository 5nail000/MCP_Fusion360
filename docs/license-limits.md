# Лицензия

Сервер не зашивает тип лицензии. `health_check` читает её у живого Fusion. `LICENSE_BLOCKED` появляется только когда API отказал.

На 2026-09-28 API сообщил Trial (окончание 2026-10-28), хотя в учётной записи ожидался Personal Use. После окончания Trial `scripts/smoke.py` нужно прогнать снова: набор экспортов может сузиться.

## Что уже наблюдалось на Trial

- STEP, STL, 3MF, OBJ, F3D, SMT, USD и IGES у куба записались.
- SAT вернулся без файла.
- Локальный снимок вьюпорта записался, когда окно Fusion не было свёрнуто.

## Ограничения Personal Use, которые остаются в силе после Trial

- Нет Simulation и Generative Design.
- CAM без быстрых перемещений и без смены инструмента. Постпроцессор для FFF Bambu Lab этим сервером не подменяется.
- Чертёж Fusion — один лист и печать, и только если у документа уже есть сохранённый DataFile. Без подтверждения сервер не сохраняет модель в облако и пишет запасной SVG.
- Одновременно активно не больше 10 документов. Повторный `new_design` с тем же именем очищает таймлайн документа `FCA_<имя>`, а не плодит копии.
- IGES и SAT на Personal Use могут быть закрыты. Ошибка API с текстом про лицензию становится `LICENSE_BLOCKED`.

Windows 10 после 2025-10-14 Autodesk не поддерживает. На этой машине Windows 11 недоступна из-за процессора. После каждого обновления Fusion запускай `scripts/smoke.py` и `scripts/discover_official_tools.py`.
