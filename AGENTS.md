# Инструкции для AI-агента: MCP_Fusion360

Этот репозиторий — рабочая среда **Cursor → fusion-cad-ai → официальный MCP Fusion → Autodesk Fusion**.

Агент принимает инженерное решение. Детерминированный runtime строит геометрию. Модель — параметрический исходник в `models/`, один и тот же для CLI и MCP.

## Архитектура

1. Cursor читает `.cursor/mcp.json`.
2. `fusion-official` — HTTP `http://127.0.0.1:27182/mcp`.
3. `fusion-cad-ai` — stdio, Python 3.12, пакет `mcp`.
4. Скрипты выполняются в Python 3.14 внутри Fusion. Пакет `fca_rt` грузится из `fusion_runtime/` без записи в `sys.path`.
5. STEP — мастер. STL и 3MF — производные. F3D — архив Fusion.
6. История — Git. Рабочую модель не перезаписывают молча.

## Перед работой

1. Выпиши параметры и единицы.
2. Размер без единицы — это ошибка, а не повод выбрать мм.
3. Имена параметров содержат единицу: `length_mm`, `angle_deg`.
4. Не закрывай и не сохраняй документы, которые открыл человек. Новые документы называются `FCA_<имя>`.
5. Не импортируй `adsk` в `models/` и в `fusion_cad_ai/`.

## Цикл построения

1. Измени параметрическую модель.
2. Собери её через `execute_file` или `scripts/run_pipeline.py`.
3. `validate` проверяет здоровье фич, объём и солид. При FAIL не экспортируй.
4. `measure` и `inspect_part` сверяют bbox и отверстия.
5. `render_view` сохраняет PNG. Смотри картинку: отверстия, симметрия, лишние тела.
6. Экспорт сначала попадает в `.runtime/verify`. В `exports/` файл копируется только после PASS.

Геометрия без ошибок Python ещё не деталь, которую можно печатать.

## Куда писать

| Что | Куда |
| --- | --- |
| Детали | `models/parts/` |
| Сборки | `models/assemblies/` |
| Повторные компоненты | `models/lib/` |
| STEP | `exports/step/` |
| STL | `exports/stl/` |
| 3MF | `exports/3mf/` |
| F3D | `exports/f3d/` |
| Preview | `renders/` |
| Референсы | `references/` |

Логи скриптов — через `fusion_cad_ai.logger.log`. Строка начинается с локального времени. Сервер MCP пишет лог в stderr: stdout занят протоколом.

## Запрещено без явной просьбы

- удалять файлы вне `exports/` и `renders/`;
- ставить пакеты в Python Fusion;
- писать глобальный `~\.cursor\mcp.json`;
- подключать community CadQuery MCP;
- удалять облачные проекты и документы;
- коммитить `.runtime`, `.venv`, токены и абсолютные пути профиля.

Коммит и push идут через `commit-message.txt` в корне. Этот файл перечислен в `.gitignore`. Перед push запускай `scripts/precommit_check.ps1`.
